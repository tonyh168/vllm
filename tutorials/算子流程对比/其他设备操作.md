# vLLM 中前向计算图和 Platform 之外的设备操作

> 本文档梳理 vLLM 中**既不在模型前向计算图（forward pass）中，也不在 `vllm/platforms/` 平台抽象代码中**的设备操作和算子。
> 这些操作服务于 vLLM 的运行时基础设施：调度、内存管理、通信、采样、图捕获等。

---

## 总结

这些操作按功能维度分类：

| 类别 | 关键文件 | 说明 |
|------|----------|------|
| **KV Cache 搬运** | `csrc/cache_kernels.cu`, `simple_kv_offload/cuda_mem_ops.py` | swap, offload, gather, convert |
| **采样算子** | `csrc/sampler.cu`, `csrc/topk.cu`, `v1/sample/ops/` | repetition penalty, top-k/top-p |
| **分布式通信** | `csrc/custom_all_reduce.cu`, `distributed/` | custom AR, NCCL, IPC, symmetric mem |
| **Expert 重平衡** | `distributed/eplb/` | 异步 P2P 权重搬运 |
| **内存管理** | `device_allocator/cumem.py` | pluggable allocator, sleep/wake |
| **CUDAGraph** | `compilation/cuda_graph.py`, `v1/worker/` | capture/replay 生命周期 |
| **异步拷贝** | `v1/worker/gpu_model_runner.py`, `offloader/` | D2H output copy, H2D weight prefetch |
| **Block Table** | `v1/worker/gpu/block_table.py` | Triton 核管理 paged 元数据 |
| **Spec Decode** | `v1/spec_decode/ngram_proposer_gpu.py` | GPU n-gram 匹配 |
| **工具** | `csrc/cuda_view.cu`, `csrc/torch_bindings.cpp` | weak_ref, cuda_view, workspace |
| **Profiling** | `profiler/wrapper.py`, `v1/worker/gpu_worker.py` | 内存 profiling, NVTX |

如果做**新硬件适配**，这些操作中最关键需要重新实现的是：
1. **KV cache swap** — 依赖 CUDA memcpy / cuMemcpyBatchAsync
2. **Custom all-reduce** — 依赖 CUDA IPC 和 GPU 共享内存
3. **CUDAGraph capture/replay** — 依赖 CUDA Graph API
4. **CuMem allocator** — 依赖 cuMem 虚拟内存管理 API
5. **Block table Triton 核** — 可以用 Triton 跨平台，但需确认支持
